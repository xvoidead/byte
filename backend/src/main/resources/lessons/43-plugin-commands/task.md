Добавьте команды `/msg <игрок> <текст>` и `/broadcast <текст>`.

- `/msg` отправляет адресату `От <отправитель>: <текст>`, а отправителю — `Кому <адресат>: <текст>`.
- Если игрок не в сети, напечатайте `Игрок <имя> не найден.`
- Для пустых или неверных аргументов покажите подсказку об использовании.
- `/broadcast` доступна только оператору (`isOp()`). Для обычного игрока ответьте `Только операторы могут объявлять.` Оператор рассылает всем онлайн игрокам `[Объявление] <текст>`.

Команды уже описаны в `resources/plugin.yml`, а `Main.java` поднимает MockBukkit и исполняет строки `join`, `op` и `cmd` из примера. Команда в сценарии пишется без начального `/`, например `cmd Steve msg Alex привет`.
