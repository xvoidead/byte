**Цикл** позволяет выполнить один и тот же код много раз.

## Цикл for

Используется, когда заранее известно, сколько раз нужно повторить действие:

```java
for (int i = 1; i <= 5; i++) {
    System.out.println("Шаг " + i);
}
```

В заголовке три части через `;`:

1. `int i = 1` — **инициализация**, выполняется один раз в начале;
2. `i <= 5` — **условие**, проверяется перед каждой итерацией;
3. `i++` — **шаг**, выполняется после каждой итерации.

## Цикл while

Повторяет тело, пока условие истинно. Удобен, когда число повторений заранее неизвестно:

```java
int n = 1;
while (n < 1000) {
    n = n * 2;
}
System.out.println(n); // 1024
```

Есть и вариант `do { ... } while (условие);` — он выполняет тело хотя бы один раз.

## break и continue

- `break` — немедленно выйти из цикла;
- `continue` — пропустить остаток текущей итерации и перейти к следующей.

```java
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        continue; // пропускаем чётные
    }
    if (i > 7) {
        break;    // останавливаемся
    }
    System.out.println(i); // 1 3 5 7
}
```

## Накопление результата

Типичный приём — завести переменную до цикла и изменять её внутри:

```java
int sum = 0;
for (int i = 1; i <= 100; i++) {
    sum += i;
}
System.out.println(sum); // 5050
```

## Бесконечный цикл

Если условие никогда не станет ложным, цикл не закончится. В нашей IDE программа будет остановлена через несколько секунд с сообщением о превышении времени.
