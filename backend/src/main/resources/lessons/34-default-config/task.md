В `resources/config.yml` лежат настройки по умолчанию:

```yaml
# Настройки сервера
server-name: Byte Craft
max-players: 20
pvp: true
language: ru
```

Программа работает с `config.yml` в рабочей папке:

1. Если `config.yml` нет, скопируйте туда файл из ресурсов **как есть**, с комментарием, и выведите `Создан config.yml из настроек по умолчанию`.
2. Прочитайте `config.yml`. Добавьте в него ключи, которых там нет, со значениями по умолчанию. Остальные ключи, в том числе лишние, не трогайте. Новые ключи идут в конец файла в том же порядке, что и в ресурсах.
3. Если что-то добавилось, сохраните файл методом `save` и выведите `Добавлены ключи: pvp, language`. Если все ключи уже были, выведите `Конфиг в порядке` и не перезаписывайте файл.
4. В конце выведите `Сервер НАЗВАНИЕ, мест: N`.

Пустой файл считается конфигом без ключей. Методы `loadDefaults` и `save` уже написаны.
