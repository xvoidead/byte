Практикум Bukkit/Paper: разберём тему на небольших шагах и сразу проверим её на сценарии MockBukkit.

## Храним прогресс

Создайте `Map<UUID, Integer>`. В обработчике `BlockBreakEvent` сначала отфильтруйте материал: засчитываем только `STONE`. Для остальных блоков сразу выйдите через `return`.

```quiz
? Засчитает ли квест DIRT после проверки на STONE?
- Да, любой блок подходит
+ Нет, обработчик завершится
- Только для оператора
> Ранний return исключает неподходящие события.
```

## Увеличиваем и завершаем

`merge(uuid, 1, Integer::sum)` увеличивает счёт. Сохраните результат и сравните его с целью. Сообщение о завершении отправляйте только при `count == 3`.

```quiz
? Почему проверка count == 3 точнее, чем count >= 3?
- Считает меньше блоков
+ Поздравляет только при достижении цели
- Удаляет игрока из Map
> Точное равенство не повторит поздравление после завершения.
```

## Показываем состояние

Команда `/quest` использует `getOrDefault(uuid, 0)`, затем ограничивает число целью через `Math.min`. Так новый игрок видит 0/3, а уже выполнивший — 3/3.

```quiz
? Что покажет команда до первого блока?
- Прогресс: null/3
+ Прогресс: 0/3
- Квест выполнен
> Значение по умолчанию равно нулю.
```
