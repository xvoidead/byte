Дочитайте конфиг сервера в `record ServerConfig` и проверьте его. Классы `Main`, `Difficulty` и `ConfigException` уже готовы, работать нужно в `ServerConfig.java`.

| Ключ | Правило | Ошибка |
|------|---------|--------|
| `server-name` | обязателен, не пустой | `server-name не задан` |
| `max-players` | обязателен, целое число больше 0 | `max-players не задан`, `max-players должен быть целым числом`, `max-players должен быть больше 0` |
| `difficulty` | обязателен, одно из `peaceful`, `easy`, `normal`, `hard` (регистр не важен) | `difficulty не задан`, `difficulty должен быть одним из: peaceful, easy, normal, hard` |
| `spawn-protection` | необязателен (по умолчанию 16), целое число не меньше 0 | `spawn-protection должен быть целым числом`, `spawn-protection не может быть отрицательным` |

Соберите **все** ошибки в том порядке, в каком ключи идут в таблице, и бросьте `ConfigException` со списком. `Main` напечатает их так:

```
Ошибки в config.yml:
- max-players должен быть больше 0
```

Если файл не читается, в списке одна ошибка:

- файла нет — `файл не найден`;
- YAML сломан или в файле не пары «ключ: значение» — `файл не читается как YAML`.

Пустой файл — это конфиг без ключей.
