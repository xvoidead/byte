Таблица очков игроков хранится в `players.json`. Команды методов `add`, `score` и `top` уже работают. Осталось научить программу загружать и сохранять игроков, то есть дописать `load`, `save` и обработку повреждённого файла.

Команды приходят по одной на строке. При запуске вводите их прямо в консоли, а когда закончите, нажмите «Конец ввода».

| Команда | Вывод |
|---------|-------|
| `add ИМЯ` | `Добавлен ИМЯ` или `ИМЯ уже есть` |
| `score ИМЯ N` | `ИМЯ: ОЧКИ` или `Нет игрока ИМЯ` |
| `top` | `1. ИМЯ — ОЧКИ` по убыванию очков или `Игроков нет` |

Что нужно сделать:

1. При запуске загрузите игроков из `players.json`. Если файла нет или он пустой, начните с пустого списка.
2. После всех команд сохраните список в `players.json` с отступами, как в примере ниже, и выведите `Сохранено игроков: N`.
3. Если файл повреждён (сломанный JSON или не список), выведите `Файл players.json повреждён` и завершите программу. Команды не выполняйте, а файл не трогайте, чтобы не потерять данные.

Если у игрока в файле нет поля `score`, у него 0 очков.

Формат файла:

```json
[
  {
    "name": "Ада",
    "score": 100
  }
]
```
