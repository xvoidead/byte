В записи `List<String>` угловые скобки говорят: это список **строк**. Такие классы называются **обобщёнными** (generics): они написаны один раз, а работают с любым типом.

## Зачем это нужно

Без обобщений список хранил бы «что угодно», и ошибка вылезла бы только при запуске:

```java
List names = new ArrayList();      // старый стиль, без типа
names.add("Аня");
names.add(42);                     // компилятор не возражает
String first = (String) names.get(1);   // ClassCastException при запуске!
```

С обобщениями компилятор сам следит за типами:

```java
List<String> names = new ArrayList<>();
names.add(42);                     // ошибка компиляции — сразу видно
```

## Свой обобщённый класс

Параметр типа пишется в угловых скобках после имени класса. Обычно его называют одной заглавной буквой: `T` — type, `E` — element, `K` и `V` — key и value.

```java
class Box<T> {
    private T value;

    void put(T value) {
        this.value = value;
    }

    T get() {
        return value;
    }
}

Box<String> box = new Box<>();
box.put("подарок");
String inside = box.get();         // приведение не нужно
```

## Обобщённые методы

Параметр типа можно объявить и у отдельного метода — перед типом результата:

```java
static <T> T last(List<T> list) {
    return list.get(list.size() - 1);
}

String s = last(List.of("a", "b"));     // T = String
Integer n = last(List.of(1, 2, 3));     // T = Integer
```


## Только объекты

Параметром типа может быть только класс — не примитив. Для чисел используют классы-обёртки: `Integer` вместо `int`, `Double` вместо `double`, `Character` вместо `char`. Java сама превращает одно в другое (это называется автоупаковкой).

```quiz
? Почему нельзя написать `List<int>`?
- int слишком маленький тип
+ Параметром типа может быть только класс, поэтому для чисел используют Integer
- List работает только со строками
- Можно, это просто плохой стиль
> Обобщения работают со ссылочными типами. `int` — примитив, его «объектная» версия — `Integer`.
```

## Ограничения на тип

Иногда методу нужно что-то уметь делать с элементами — например, сравнивать их. Тогда тип ограничивают через `extends`:

```java
static <T extends Comparable<T>> T max(List<T> list) {
    T best = list.get(0);
    for (T item : list) {
        if (item.compareTo(best) > 0) {
            best = item;
        }
    }
    return best;
}
```

Такой метод примет список строк или чисел, но не список объектов, которые не умеют сравниваться.

## Стек — обобщённая структура данных

**Стек** — стопка элементов: класть и забирать можно только сверху. Последним пришёл — первым ушёл. Стек нужен для отмены действий в редакторах, истории браузера и проверки скобок. Его удобно написать обобщённым классом поверх `ArrayList`: `push` добавляет в конец, `pop` снимает последний элемент.
