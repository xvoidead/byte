Напишите обобщённый класс `Stack<T>` на основе `ArrayList` с методами `push(T item)`, `T pop()`, `T peek()`, `boolean isEmpty()` и `int size()`. Затем используйте его для проверки скобок.

Каждая строка ввода — текст со скобками `()`, `[]` и `{}`. Для каждой строки выведите:

- `OK` — если все скобки закрыты правильно;
- `Ошибка в позиции N` — если встретилась закрывающая скобка, которой нет пары (или пара другого вида); `N` — номер этой скобки в строке, начиная с 1;
- `Не закрыто скобок: K` — если ошибок не было, но в конце остались открытые скобки.

Остальные символы игнорируйте.

Для ввода

```
(a[b]{c})
(]
((
```

вывод:

```
OK
Ошибка в позиции 2
Не закрыто скобок: 2
```
