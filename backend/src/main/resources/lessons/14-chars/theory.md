Строка состоит из символов, а каждый символ в компьютере — это число, его **код**. Если понять это, можно делать с текстом удивительные вещи — например, шифровать его.

## Тип char

Символ записывается в одинарных кавычках. У каждого символа есть код в таблице Unicode:

```java
char letter = 'A';
System.out.println((int) letter);   // 65
System.out.println((char) 66);      // B
```

Буквы латинского алфавита идут подряд: `'a'` — 97, `'b'` — 98, …, `'z'` — 122. Заглавные — с 65 (`'A'`) по 90 (`'Z'`). Цифры `'0'`…`'9'` — с 48 по 57.

## Арифметика символов

С символом можно считать как с числом. Результат арифметики — `int`, поэтому для получения символа нужно приведение:

```java
char c = 'a';
int code = c + 1;             // 98
char next = (char) (c + 1);   // 'b'
int position = 'e' - 'a';     // 4 — номер буквы в алфавите с нуля
int digit = '7' - '0';        // 7 — символ-цифра в число
```

```quiz
? Что выведет программа?

> Сложение символа с числом даёт `int`: код `'a'` (97) плюс 1 — это 98. Чтобы получить `b`, нужно привести результат: `(char) ('a' + 1)`.
```

## Проверки символов

Класс `Character` умеет определять вид символа:

```java
Character.isLetter('ж')       // true
Character.isDigit('7')        // true
Character.isUpperCase('Q')    // true
Character.isWhitespace(' ')   // true
Character.toUpperCase('q')    // 'Q'
```

Для проверки, латинская ли это строчная буква, удобно сравнение: `c >= 'a' && c <= 'z'`.

## Алфавит по кругу

Шифр Цезаря сдвигает каждую букву на `k` позиций: при `k = 3` буква `a` становится `d`, `b` — `e`. Буквы в конце алфавита «заворачиваются» в начало: `z` → `c`.

Чтобы сдвиг работал по кругу, переводим букву в номер от 0 до 25, сдвигаем и берём остаток от деления на 26:

```java
char shifted = (char) ('a' + (c - 'a' + k) % 26);
```

Если сдвиг может быть отрицательным, обычный `%` вернёт отрицательный остаток. Поможет `Math.floorMod`, который всегда даёт число от 0 до 25:

```java
char shifted = (char) ('a' + Math.floorMod(c - 'a' + k, 26));
```

```quiz
? Что выведет программа?
    System.out.println((char) ('z' + 1));

> После `z` (код 122) в таблице идёт символ `{` (код 123). Алфавит сам по себе по кругу не заворачивается — для этого нужен остаток от деления.
```

## Собираем строку из символов

Строку перебирают по символам через `charAt` или `toCharArray`, а новую собирают в `StringBuilder`:

```java
StringBuilder result = new StringBuilder();
for (char c : text.toCharArray()) {
    result.append(Character.toUpperCase(c));
}
System.out.println(result);
```
