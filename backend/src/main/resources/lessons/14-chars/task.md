Реализуйте шифр Цезаря для латинских букв.

Первая строка ввода — сдвиг `k` (от −1000 до 1000), вторая — текст. Сдвиньте каждую латинскую букву на `k` позиций по кругу, сохранив регистр: строчные остаются строчными, заглавные — заглавными. Все остальные символы (пробелы, цифры, знаки препинания, кириллица) оставьте без изменений.

Для ввода

```
3
Hello, World!
```

вывод:

```
Khoor, Zruog!
```

Сдвиг одной буквы вынесите в отдельный метод `static char shift(char c, int k)`.
