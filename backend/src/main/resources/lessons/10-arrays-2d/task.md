Первая строка ввода — размеры таблицы `n` и `m` (от 1 до 10): число строк и столбцов. Дальше идут `n` строк по `m` целых чисел.

Выведите **транспонированную** таблицу — `m` строк по `n` чисел через пробел, — а затем строку `Суммы строк:` с суммами строк **исходной** таблицы.

Для ввода

```
2 3
1 2 3
4 5 6
```

вывод:

```
1 4
2 5
3 6
Суммы строк: 6 15
```
