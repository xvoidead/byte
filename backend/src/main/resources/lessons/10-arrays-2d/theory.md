Обычный массив — это ряд значений. Но многие данные устроены как таблица: оценки учеников по предметам, клетки шахматной доски, пиксели картинки. Для них есть **двумерные массивы**.

## Создание

Двумерный массив — это массив массивов. У элемента два индекса: номер строки и номер столбца.

```java
int[][] grid = new int[3][4];        // 3 строки по 4 столбца, заполнено нулями
int[][] m = {
    {1, 2, 3},
    {4, 5, 6},
};

System.out.println(m[0][2]);         // 3 — строка 0, столбец 2
m[1][0] = 40;                        // замена элемента
System.out.println(m.length);        // 2 — число строк
System.out.println(m[0].length);     // 3 — число столбцов в строке 0
```

```quiz
? Что выведет программа?
    int[][] m = {{1, 2, 3}, {4, 5, 6}};
    System.out.println(m.length + " " + m[1].length + " " + m[1][2]);
+ 2 3 6
- 3 2 6
- 2 3 5
- 6 3 2
> `m.length` — число строк (2), `m[1].length` — число элементов во второй строке (3), `m[1][2]` — третий элемент второй строки (6).
```

## Обход

Двумерный массив обходят вложенными циклами: внешний — по строкам, внутренний — по столбцам.

```java
for (int row = 0; row < m.length; row++) {
    for (int col = 0; col < m[row].length; col++) {
        System.out.print(m[row][col] + " ");
    }
    System.out.println();
}
```

То же самое через for-each:

```java
for (int[] line : m) {
    for (int value : line) {
        System.out.print(value + " ");
    }
    System.out.println();
}
```

## Строки и столбцы

Сумма строки — проход по одной строке. Сумма столбца — проход по всем строкам с фиксированным номером столбца:

```java
int rowSum = 0;
for (int col = 0; col < m[0].length; col++) {
    rowSum += m[0][col];          // строка 0
}

int colSum = 0;
for (int row = 0; row < m.length; row++) {
    colSum += m[row][1];          // столбец 1
}
```

**Транспонирование** — поворот таблицы так, что строки становятся столбцами: элемент `[i][j]` переходит в `[j][i]`.

```quiz
? Какой индекс у элемента в правом нижнем углу массива `new int[3][5]`?
- [3][5]
+ [2][4]
- [5][3]
- [4][2]
> Строк три — индексы от 0 до 2, столбцов пять — индексы от 0 до 4. Правый нижний угол — `[2][4]`.
```

## Чтение таблицы из ввода

Обычно сначала вводят размеры, а потом значения построчно:

```java
Scanner in = new Scanner(System.in);
int rows = in.nextInt();
int cols = in.nextInt();
int[][] table = new int[rows][cols];
for (int r = 0; r < rows; r++) {
    for (int c = 0; c < cols; c++) {
        table[r][c] = in.nextInt();
    }
}
```

## Быстрый просмотр

Для отладки удобен `Arrays.deepToString` — он печатает весь двумерный массив:

```java
System.out.println(Arrays.deepToString(m)); // [[1, 2, 3], [4, 5, 6]]
```
