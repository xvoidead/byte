Каждую секунду отправляйте всем игрокам онлайн сообщение `Прошла секунда.`. Сервер работает примерно с частотой 20 тиков в секунду. Используйте `ServerTickEvents.END_SERVER_TICK`, счётчик тиков и список игроков из `server.getPlayerManager().getPlayerList()`.

Не используйте `Thread.sleep`: он блокирует поток сервера. Сценарий принимает `join <имя>` и `tick <количество>`.
