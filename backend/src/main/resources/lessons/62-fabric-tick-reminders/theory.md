Событие тика вызывается много раз в секунду. Счётчик позволяет запускать действие через выбранный интервал, не останавливая сервер.

## Подписываемся на конец тика

Регистрируйте `ServerTickEvents.END_SERVER_TICK` в `onInitialize()`. Callback получает сервер.

```java
ServerTickEvents.END_SERVER_TICK.register(server -> {
    // короткая работа в конце тика
});
```

```quiz
? Что означает END_SERVER_TICK?
- Клиент нажал клавишу
+ Сервер завершает очередной тик
- Игрок вышел из мира
> Это callback жизненного цикла серверного тика.
```

## Сохраняем счётчик между вызовами

Счётчик должен быть полем объекта мода. Локальная переменная внутри callback создавалась бы заново при каждом тике.

```java
private int ticks;

private void onTick(MinecraftServer server) {
    ticks++;
}
```

```quiz
? Где хранить ticks, чтобы значение сохранялось между callback-вызовами?
- В локальной переменной метода
+ В поле объекта мода
- В аргументе Text.literal
> Поле живёт всё время, пока существует экземпляр мода.
```

## Проверяем интервал

Оператор `%` даёт остаток от деления. Когда `ticks % 5 == 0`, прошло ровно пять, десять и так далее тиков. Для сообщения используйте `PlayerManager.broadcast`.

Не используйте `Thread.sleep`: он блокирует поток сервера.

```quiz
? При каком значении ticks условие ticks % 5 == 0 истинно?
- 4
+ 5
- 6
> Пять делится на пять без остатка.
```
