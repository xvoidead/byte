## Добавляем игрока

Поле `Set<UUID>` хранит только подключённых игроков. В `PlayerJoinEvent` добавьте UUID и при желании уберите стандартное сообщение сервера.

```java
online.add(event.getPlayer().getUniqueId());
event.setJoinMessage(null);
```

```quiz
? Что хранит online после события входа?
- Игроков из истории
+ UUID подключённых игроков
- Сломанные блоки
> Set должен описывать текущее состояние.
```

## Удаляем при выходе

`PlayerQuitEvent` срабатывает при отключении. Удалите UUID: `online.remove(event.getPlayer().getUniqueId())`. Если забыть это действие, множество будет считать уже вышедших игроков.

```quiz
? Что нужно вызвать при отключении игрока?
- online.add(uuid)
+ online.remove(uuid)
- online.clear()
> Выход удаляет только отключившегося игрока.
```

## Показываем число

Команда `/online` может отправить `online.size()` через `CommandSender.sendMessage`. В учебном сценарии плагин загружается до подключения игроков, поэтому состояние заполняется событиями.

```quiz
? Что возвращает online.size()?
- Максимум игроков сервера
+ Число UUID в Set
- Число команд в plugin.yml
> size считает элементы коллекции.
```
