В программе магазина есть команды для работы со складом, но запросы склеены из строк. На товаре `Д'Артаньян` программа падает, а хитрый пользователь может увидеть или удалить весь склад. Перепишите запросы на `PreparedStatement` с параметрами.

Команды (название может содержать пробелы и любые символы):

| Команда | Что делает | Ответ |
|---------|-----------|-------|
| `add <цена> <название>` | добавляет товар | `Добавлен: <название> (<цена>)` или `Уже есть: <название>` |
| `price <название>` | показывает цену | `<название>: <цена>` или `Не найден: <название>` |
| `cheaper <цена>` | товары не дороже цены — по цене, при равной цене по названию | строки `<название> — <цена>` или `Ничего не найдено` |
| `remove <название>` | удаляет товар | `Удалён: <название>` или `Не найден: <название>` |
| `count` | считает товары | `Товаров: <число>` |

Разбор команд и таблица уже готовы, работать нужно в методах `add`, `price`, `cheaper`, `remove`, `count`.
