Многие игровые действия в Bukkit представлены событиями: вход игрока, ломание блока, установка блока, получение урона. Плагин может отреагировать на событие или отменить его.

## События блоков

`BlockBreakEvent` содержит игрока и сломанный блок. `BlockPlaceEvent` — игрока и поставленный блок. В обоих случаях блок можно получить через `event.getBlock()` или `event.getBlockPlaced()`.

```java
@EventHandler
public void onBreak(BlockBreakEvent event) {
    Player player = event.getPlayer();
    Location location = event.getBlock().getLocation();
    player.sendMessage("Блок: " + location.getBlockX());
}
```

Все event-handler методы должны быть зарегистрированы через `PluginManager.registerEvents`, как и обработчик входа из предыдущего урока.

```quiz
? Что сообщает BlockBreakEvent?
- Что игрок вошёл на сервер
+ Что игрок попытался сломать блок
- Что сработал таймер
> Bukkit создаёт BlockBreakEvent при попытке сломать блок; плагин может проверить игрока и координаты.
```

## Отменяем действие

У событий, которые можно запретить, есть `setCancelled(true)`. Отмена должна произойти до того, как сервер завершит обработку события. Игрока удобно предупредить прямо в обработчике.

```java
if (nearSpawn(location)) {
    event.setCancelled(true);
    player.sendMessage("Здесь строить нельзя.");
}
```

Если метод получает `BlockPlaceEvent`, для отмены установки вызывается такой же `setCancelled(true)`. События разных типов не связаны наследованием, поэтому для каждого нужен свой параметр метода.

```quiz
? Что произойдёт после event.setCancelled(true) в обработчике BlockBreakEvent?
- Игроку выдадут блок
+ Сервер не сломает блок в результате этого события
- Игрок станет оператором
> Отмена запрещает Bukkit выполнить действие, которое вызвало событие.
```

## Координаты и исключения

Зона спавна — круг радиуса 5 блоков по горизонтали. Сравнивать расстояние можно без `sqrt`: `x*x + z*z <= 5*5`. Для блока координаты доступны через `Location`; у блока также есть `getX()` и `getZ()`.

Операторы часто получают особые права на сервере. Проверяйте `event.getPlayer().isOp()` до отмены: если игрок оператор, обработчик должен сразу завершиться или пропустить запрет.
