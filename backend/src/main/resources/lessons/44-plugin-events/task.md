Защитите квадратную область вокруг спавна: блок нельзя ломать или ставить, если `x² + z² ≤ 25`. Оператор (`op`) может строить и ломать без ограничений. При отмене события покажите игроку соответствующее сообщение:

- ломание: `У спавна нельзя ломать блоки.`
- установка: `У спавна нельзя ставить блоки.`

Обрабатывайте `BlockBreakEvent` и `BlockPlaceEvent`. Если событие разрешено, ничего не выводите. Сценарий понимает `break <игрок> x y z MATERIAL` и `place <игрок> x y z MATERIAL`.
