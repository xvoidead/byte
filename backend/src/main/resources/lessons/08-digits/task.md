Программа получает целое число `n` (по модулю не больше 10¹⁸, может быть отрицательным). Выведите:

1. количество цифр;
2. сумму цифр;
3. число, записанное задом наперёд (знак минус сохраняется, ведущие нули пропадают: 1200 → 21);
4. является ли запись числа палиндромом — читается ли одинаково в обе стороны без учёта знака.

Для ввода `-1200`:

```
Цифр: 4
Сумма цифр: 3
Наоборот: -21
Палиндром: нет
```

Решите задачу арифметикой — остатком от деления и делением, не превращая число в строку. Не забудьте про число 0: у него одна цифра.
