Цикл `while` удобен, когда заранее неизвестно, сколько шагов понадобится. Классический пример — работа с цифрами числа: мы не знаем, сколько их, пока не начнём считать.

## Последняя цифра и остаток

Два оператора делают всю работу:

- `n % 10` — последняя цифра числа;
- `n / 10` — число без последней цифры (деление целых чисел отбрасывает остаток).

```java
int n = 4096;
System.out.println(n % 10);  // 6
System.out.println(n / 10);  // 409
```

```quiz
? Что выведет программа?
    int n = 1234;
    System.out.println(n % 10 + " " + n / 10 % 10);
+ 4 3
- 4 123
- 1 2
- 3 4
> `n % 10` — последняя цифра 4. `n / 10` — это 123, а его последняя цифра — 3.
```

## Перебираем все цифры

Повторяем «взять последнюю цифру — отрезать её», пока число не станет нулём:

```java
int n = 4096;
int sum = 0;
while (n > 0) {
    int digit = n % 10;
    sum += digit;
    n /= 10;
}
System.out.println(sum); // 19
```

Обратите внимание: цикл меняет `n`. Если исходное число ещё понадобится, скопируйте его в другую переменную заранее.

## Переворачиваем число

Чтобы получить число задом наперёд, каждую новую цифру «приписываем» справа к результату:

```java
int n = 123;
int reversed = 0;
while (n > 0) {
    reversed = reversed * 10 + n % 10;
    n /= 10;
}
// reversed: 0 → 3 → 32 → 321
```

```quiz
? Что выведет программа?
    int n = 507;
    int reversed = 0;
    while (n > 0) {
        reversed = reversed * 10 + n % 10;
        n /= 10;
    }
    System.out.println(reversed);
+ 705
- 750
- 57
- 507
> Цифры снимаются справа налево — 7, 0, 5 — и приписываются к результату: 7, 70, 705.
```

## Цикл do-while

У числа 0 одна цифра, но цикл `while (n > 0)` не выполнится ни разу. Здесь поможет `do-while`: он **сначала выполняет тело, а потом проверяет условие**, поэтому тело выполнится хотя бы один раз.

```java
int count = 0;
do {
    count++;
    n /= 10;
} while (n > 0);
```

## Отрицательные и большие числа

- Для отрицательного числа `%` вернёт отрицательную цифру. Обычно работают с модулем: `Math.abs(n)`, а знак учитывают отдельно.
- Если число может быть больше двух миллиардов, используйте `long` и `in.nextLong()`.
