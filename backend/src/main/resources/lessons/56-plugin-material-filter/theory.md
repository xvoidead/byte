## Перечень материалов

Bukkit описывает блоки перечислением `Material`. Используйте отдельное неизменяемое множество: `Set.of(Material.STONE, Material.DIAMOND_ORE)`. Так список правил виден сразу.

```quiz
? Что такое Material.STONE?
- Строка
+ Значение перечисления Material
- Координата блока
> Material содержит типы блоков и предметов Bukkit.
```

## Отменяем запрещённое событие

В `BlockBreakEvent` получите тип через `event.getBlock().getType()`. Если `allowed.contains(type)` вернул false, вызовите `event.setCancelled(true)` и сообщите игроку.

```java
if (!allowed.contains(event.getBlock().getType())) {
    event.setCancelled(true);
    event.getPlayer().sendMessage("Этот блок нельзя добывать.");
}
```

```quiz
? Что произойдёт после setCancelled(true)?
- Блок всё равно сломается
+ Сервер отменит ломание
- Игрок станет оператором
> Отмена запрещает действие, вызвавшее событие.
```

## Проверяем оба исхода

Нужны тесты и для разрешённого, и для запрещённого блока: иначе правило, которое случайно отменяет всё, может пройти. Сценарий `break Steve x y z MATERIAL` вызывает событие Bukkit.

```quiz
? Зачем отдельно тестировать разрешённый блок?
- Чтобы выдать за него награду
+ Чтобы убедиться, что фильтр не блокирует всё
- Чтобы изменить Material
> Корректный фильтр пропускает разрешённые события.
```
