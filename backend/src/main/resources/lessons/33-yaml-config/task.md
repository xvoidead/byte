Рядом с программой лежит `config.yml` — настройки игрового сервера:

```yaml
# Настройки сервера
server-name: Byte Craft
max-players: 20
pvp: true
spawn:
  x: 100
  y: 64
motd:
  - Добро пожаловать!
  - Не ломайте спавн
```

Прочитайте его через SnakeYAML и выведите:

```
Сервер: Byte Craft
Игроков: до 20
PvP: включён
Спавн: 100, 64
Сообщения: 2
- Добро пожаловать!
- Не ломайте спавн
```

- Если `pvp` ложно, выведите `PvP: выключен`.
- Раздела `motd` может не быть — тогда сообщений 0.
- Если файла `config.yml` нет, выведите `Нет файла config.yml` и больше ничего.

Проверка подставляет свои конфиги, поэтому все значения нужно брать из файла.
