**Переменная** — это именованная ячейка памяти, в которой хранится значение. В Java у каждой переменной есть **тип**, и он не меняется.

## Объявление переменной

```java
int age = 25;              // целое число
double price = 99.90;      // дробное число
boolean isStudent = true;  // логическое значение: true или false
char grade = 'A';          // один символ — в одинарных кавычках
String name = "Анна";      // строка — в двойных кавычках
```

Сначала пишется тип, затем имя, затем `=` и начальное значение.

## Основные типы

| Тип | Что хранит | Пример |
|-----|------------|--------|
| `int` | целые числа примерно до ±2 млрд | `42` |
| `long` | очень большие целые числа | `9_000_000_000L` |
| `double` | дробные числа | `3.14` |
| `boolean` | истина или ложь | `true` |
| `char` | один символ | `'Я'` |
| `String` | текст | `"Java"` |

`int`, `long`, `double`, `boolean` и `char` — **примитивные типы**. `String` — это класс, но пользоваться им так же просто.

## Арифметика

```java
int a = 17;
int b = 5;
System.out.println(a + b);  // 22
System.out.println(a - b);  // 12
System.out.println(a * b);  // 85
System.out.println(a / b);  // 3  — деление целых чисел отбрасывает дробную часть!
System.out.println(a % b);  // 2  — остаток от деления
System.out.println(17.0 / 5); // 3.4
```

## Склеивание строк

Оператор `+` со строкой склеивает текст:

```java
String name = "Анна";
int age = 25;
System.out.println("Меня зовут " + name + ", мне " + age + " лет");
```

## Изменение значения

```java
int count = 10;
count = count + 5;  // 15
count += 5;         // 20 — короткая запись
count++;            // 21 — увеличить на 1
```

## Сравнения

Операторы `>`, `<`, `>=`, `<=`, `==`, `!=` дают значение типа `boolean`:

```java
int x = 10;
boolean big = x > 5;   // true
System.out.println(big);
```

## Константы

Если значение не должно меняться, объявите его как `final`:

```java
final double PI = 3.14159;
```
