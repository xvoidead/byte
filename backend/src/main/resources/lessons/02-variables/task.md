Дан прямоугольник со сторонами `width = 7` и `height = 3`.

1. Объявите переменные `width` и `height` типа `int`.
2. Вычислите площадь (`width * height`) и периметр (`2 * (width + height)`).
3. Вычислите квадрат диагонали: `width * width + height * height` и проверьте, больше ли он чем `7 * 7` (то есть длиннее ли диагональ, чем 7).

Выведите:

```
Площадь: 21
Периметр: 20
Диагональ больше 7: true
```

Считайте значения через переменные, а не пишите готовые числа — так программа будет работать для любых сторон.
