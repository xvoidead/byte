Запретите ломание блоков в круге радиуса 5 вокруг координат (0, 0). Для успешной добычи отправьте `Блок добыт!`, а для защищённой области — `У спавна нельзя ломать блоки.`

Используйте два события Fabric API:

- `PlayerBlockBreakEvents.BEFORE` — возвращайте `false`, чтобы отменить ломание;
- `PlayerBlockBreakEvents.AFTER` — реагируйте только на уже успешно сломанный блок.

Событие `break <игрок> x y z MATERIAL` запускает тестовую симуляцию ломания.
