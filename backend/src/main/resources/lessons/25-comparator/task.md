Составьте рейтинг участников олимпиады. Каждая строка ввода — имя и число баллов через пробел (до конца ввода).

Отсортируйте участников по баллам **по убыванию**, а при равных баллах — по имени **по алфавиту**. Выведите рейтинг в формате `место. Имя — баллы`.

Для ввода

```
Аня 90
Боря 75
Вика 90
Гена 60
```

вывод:

```
1. Аня — 90
2. Вика — 90
3. Боря — 75
4. Гена — 60
```

Опишите порядок с помощью `Comparator`.
