Java — один из самых популярных языков программирования. На нём пишут серверы банков и интернет-магазинов, приложения для Android и огромные корпоративные системы.

## Из чего состоит программа

Самая маленькая программа на Java выглядит так:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Привет, мир!");
    }
}
```

Разберём её по частям:

- `public class Main` — объявление **класса** с именем `Main`. В Java любой код живёт внутри классов.
- `public static void main(String[] args)` — **метод main**, точка входа. Когда программа запускается, Java ищет именно его и начинает выполнять код внутри.
- `System.out.println(...)` — команда, которая печатает текст в консоль и переходит на новую строку.
- Фигурные скобки `{ }` отмечают начало и конец блока: класса или метода.
- Точка с запятой `;` завершает каждую инструкцию.

```quiz
? С какого метода начинается выполнение программы на Java?
- С первого метода в классе
+ С метода main
- С метода start
- С конструктора класса Main
> Java ищет метод `public static void main(String[] args)` и начинает выполнение с него.
```

## Вывод текста

Текст в Java записывается в двойных кавычках и называется **строкой**:

```java
System.out.println("Первая строка");
System.out.println("Вторая строка");
System.out.print("Без перевода строки, ");
System.out.print("продолжение на той же строке");
```

`println` переводит курсор на новую строку после вывода, а `print` — нет.

```quiz
? Что выведет программа?
    System.out.print("Раз");
    System.out.println("Два");
    System.out.print("Три");
- Раз\nДва\nТри
+ РазДва\nТри
- Раз Два Три
- РазДваТри
> `print` не переводит строку, поэтому «Раз» и «Два» оказываются рядом, а после `println` «Три» печатается уже с новой строки.
```

## Комментарии

Комментарии — это заметки для людей, компилятор их игнорирует:

```java
// однострочный комментарий

/*
   многострочный
   комментарий
*/
```

## Как работать в редакторе

- Кнопка **«Запустить»** (или `Ctrl + Enter`) компилирует и выполняет программу — результат появится в консоли внизу.
- Кнопка **«Проверить»** запускает тесты задания.
- Если в коде ошибка, редактор подчеркнёт нужную строку и покажет подсказку.
