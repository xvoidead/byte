Часто программа должна вести себя по-разному в зависимости от данных. Для этого есть **условные операторы**.

## if и else

```java
int temperature = 25;

if (temperature > 30) {
    System.out.println("Жарко");
} else if (temperature > 15) {
    System.out.println("Тепло");
} else {
    System.out.println("Холодно");
}
```

Условия проверяются сверху вниз. Выполняется **первая** ветка, условие которой истинно, остальные пропускаются. Ветка `else` срабатывает, если не подошла ни одна другая.

## Логические операторы

| Оператор | Значение | Пример |
|----------|----------|--------|
| `&&` | И — оба условия истинны | `age >= 18 && age < 65` |
| `\|\|` | ИЛИ — хотя бы одно истинно | `day == 6 \|\| day == 7` |
| `!` | НЕ — инверсия | `!isEmpty` |

```java
int age = 20;
boolean hasTicket = true;
if (age >= 18 && hasTicket) {
    System.out.println("Проходите");
}
```

## Частая ошибка

Для сравнения используется `==`, а `=` — это присваивание. А ещё не ставьте `;` сразу после условия:

```java
if (x > 0);   // ← эта точка с запятой — пустая инструкция!
{
    System.out.println("Выполнится всегда");
}
```

## switch

Когда нужно сравнить одно значение с набором вариантов, удобен `switch`:

```java
int day = 3;
String name = switch (day) {
    case 1 -> "Понедельник";
    case 2 -> "Вторник";
    case 3 -> "Среда";
    case 6, 7 -> "Выходной";
    default -> "Другой день";
};
System.out.println(name); // Среда
```

Такая форма со стрелками `->` появилась в современных версиях Java и не требует `break`.

## Тернарный оператор

Короткая запись «если-иначе» для выбора значения:

```java
int a = 5, b = 9;
int max = a > b ? a : b;  // 9
```
