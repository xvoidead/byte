Первая строка ввода — количество чисел `n` (от 1 до 100), вторая — сами числа.

Отсортируйте их по возрастанию **сортировкой пузырьком** и выведите отсортированные числа через пробел. На второй строке выведите, сколько обменов соседних элементов сделала ваша сортировка.

Для ввода

```
5
3 1 4 5 2
```

вывод:

```
1 2 3 4 5
Обменов: 4
```

Готовые методы сортировки (`Arrays.sort`, `Collections.sort` и другие) использовать нельзя. Одинаковые числа местами не меняйте.
