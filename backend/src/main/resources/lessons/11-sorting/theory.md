Отсортированные данные удобно искать, сравнивать и показывать. В Java есть готовый `Arrays.sort`, но чтобы понимать, как работают программы, полезно хотя бы раз написать сортировку самому.

## Обмен значений

Почти любая сортировка переставляет элементы местами. Для обмена нужна временная переменная:

```java
int temp = a[i];
a[i] = a[j];
a[j] = temp;
```

Без неё значение потеряется:

```quiz
? Что выведет программа?
    int a = 3;
    int b = 5;
    a = b;
    b = a;
    System.out.println(a + " " + b);
- 5 3
+ 5 5
- 3 3
- 3 5
> После `a = b` исходное значение `a` (3) потеряно, и `b = a` записывает в `b` ту же пятёрку. Поэтому для обмена нужна временная переменная.
```

## Сортировка пузырьком

Идея: проходим по массиву и меняем местами соседей, если левый больше правого. После первого прохода самый большой элемент «всплывает» в конец. Повторяем, пока есть что менять.

```java
for (int pass = 0; pass < a.length - 1; pass++) {
    for (int i = 0; i < a.length - 1 - pass; i++) {
        if (a[i] > a[i + 1]) {
            int temp = a[i];
            a[i] = a[i + 1];
            a[i + 1] = temp;
        }
    }
}
```

После каждого прохода последние `pass` элементов уже стоят на своих местах, поэтому внутренний цикл становится короче.

## Сортировка выбором

Другая идея: найти минимум и поставить его на первое место, потом найти минимум среди оставшихся и поставить на второе, и так далее.

```java
for (int i = 0; i < a.length - 1; i++) {
    int min = i;
    for (int j = i + 1; j < a.length; j++) {
        if (a[j] < a[min]) {
            min = j;
        }
    }
    int temp = a[i];
    a[i] = a[min];
    a[min] = temp;
}
```

## Сколько это стоит

Обе сортировки делают около `n²/2` сравнений. Для 1000 элементов это полмиллиона сравнений, для миллиона — уже полтриллиона. Готовый `Arrays.sort` устроен хитрее и делает порядка `n · log n` операций: для миллиона — около 20 миллионов.

**Инверсия** — пара элементов, которые стоят «не в том порядке»: левый больше правого. Пузырёк за один обмен соседей исправляет ровно одну инверсию, поэтому число его обменов равно числу инверсий в массиве.

```quiz
? Сколько инверсий в массиве {3, 1, 2}?
- 1
+ 2
- 3
- 0
> Не в том порядке стоят пары (3, 1) и (3, 2). Пара (1, 2) стоит правильно.
```

## Готовая сортировка

В реальных программах используют готовое:

```java
int[] a = {5, 2, 9, 1};
Arrays.sort(a);                        // [1, 2, 5, 9]

List<String> names = new ArrayList<>(List.of("Вика", "Аня", "Боря"));
Collections.sort(names);               // [Аня, Боря, Вика]
```
