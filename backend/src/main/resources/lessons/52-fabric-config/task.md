Сделайте конфиг `config/byte.json` с двумя полями:

```json
{"enabled": true, "welcome": "Добро пожаловать, {player}!"}
```

Используйте `FabricLoader.getInstance().getConfigDir()` для папки конфигов и Gson для чтения `ModConfig`. Если файла ещё нет, создайте каталог и запишите настройки по умолчанию. При входе игрока отправляйте подставленное приветствие, только если `enabled` равно `true`.

Тесты меняют содержимое файла и проверяют вариант, когда файла нет совсем. В Byte каталог `config` отображается как папка рабочей директории; это учебный симулятор, в реальной игре Fabric Loader возвращает путь внутри каталога игры.
