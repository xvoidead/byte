Напишите метод `static boolean isPrime(int n)`, который возвращает `true`, если `n` — **простое число** (больше 1 и делится только на 1 и на себя).

Программа получает число `n`. С помощью `isPrime` выведите через пробел все простые числа от 2 до `n`, а на следующей строке — их количество:

```
2 3 5 7
Всего: 4
```

Если простых чисел нет, выведите `Простых чисел нет`.

Один из тестов проверяет `n = 20000`, поэтому метод должен быть достаточно быстрым. Подсказка: делители достаточно проверять до `√n`, то есть пока `d * d <= n`.
