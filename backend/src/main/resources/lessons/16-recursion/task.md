Решите головоломку «Ханойские башни» для `n` дисков (от 1 до 10). Диски пронумерованы от 1 (самый маленький) до `n` (самый большой) и стоят на стержне A. Перенесите их на стержень C, используя B как вспомогательный.

Выведите все ходы в формате `Диск d: X → Y`, а в конце — общее число ходов.

Для `n = 2`:

```
Диск 1: A → B
Диск 2: A → C
Диск 1: B → C
Ходов: 3
```

Напишите рекурсивный метод `hanoi`, который вызывает сам себя. Порядок ходов должен быть таким, как в алгоритме из теории.
