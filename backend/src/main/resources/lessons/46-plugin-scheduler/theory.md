Сервер Minecraft работает по циклу **тиков**. При стандартных 20 тиках в секунду таймер на 20 тиков занимает около секунды. В Bukkit отложенные действия запускает планировщик; `Thread.sleep` использовать нельзя — он задержит поток сервера.

## Однократная задача

`BukkitRunnable` — удобный класс для задачи с методом `run()`. `runTaskLater(plugin, delay)` выполнит её один раз после задержки:

```java
new BukkitRunnable() {
    @Override
    public void run() {
        player.sendMessage("Время вышло!");
    }
}.runTaskLater(this, 20L);
```

Аргумент `plugin` сообщает планировщику, кому принадлежит задача. Когда плагин выключается, Bukkit может отменить принадлежащие ему задачи.

```quiz
? Сколько секунд примерно занимают 60 тиков при скорости 20 тиков в секунду?
- 20
+ 3
- 60
> Делим число тиков на 20: 60 / 20 = 3 секунды.
```

## Повторяющаяся задача

`runTaskTimer(plugin, delay, period)` запускает задачу повторно: сначала ждёт `delay`, затем выполняет `run()` через каждый `period` тиков.

```java
new BukkitRunnable() {
    @Override
    public void run() {
        player.sendMessage("Тик!");
    }
}.runTaskTimer(this, 1L, 20L);
```

Суффикс `L` означает значение типа `long`, которое ожидают методы планировщика. Если начать с нулевой задержкой, первая попытка запуска может произойти в текущем тике, поэтому для понятного сценария используем `1L`.

```quiz
? Какой period нужен для вызова примерно раз в секунду?
- 1L
+ 20L
- 1000L
> Сервер обрабатывает около 20 тиков в секунду, поэтому интервал в 20 тиков равен примерно секунде.
```

## Отмена и проверка ввода

Повторяющаяся задача продолжит работать, пока её не отменить. Внутри `BukkitRunnable` вызовите `cancel()` при достижении нуля:

```java
if (secondsLeft == 0) {
    player.sendMessage("Старт!");
    cancel();
    return;
}
```

Ввод игрока — обычный массив строк. Сначала проверьте его длину, потом преобразуйте число. `Integer.parseInt` бросает `NumberFormatException`, если введено слово; поймайте её и покажите подсказку.

```quiz
? Что делает cancel() у выполняющегося BukkitRunnable?
- Выключает весь сервер
- Возвращает время назад
+ Останавливает дальнейшие запуски этой задачи
> Отмена относится только к задаче; плагин и сервер продолжают работать.
```
