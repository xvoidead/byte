**Множество** (`Set`) — коллекция, в которой каждый элемент встречается не больше одного раза. Оно пригодится, когда важно «есть или нет», а не «сколько раз»: уникальные посетители, теги статьи, прочитанные уроки.

## HashSet

```java
Set<String> tags = new HashSet<>();
tags.add("java");
tags.add("новичкам");
tags.add("java");                   // повтор не добавится

System.out.println(tags.size());            // 2
System.out.println(tags.contains("java"));  // true
tags.remove("новичкам");
```

`add` возвращает `true`, если элемент действительно добавился, и `false`, если он уже был. Проверка `contains` у `HashSet` работает мгновенно даже для миллиона элементов — в отличие от поиска в списке.

```quiz

    set.add("кот");

> «кот» уже есть в множестве, поэтому `add` возвращает `false`, а размер остаётся 2.
```

## Порядок элементов

- `HashSet` не гарантирует никакого порядка.
- `LinkedHashSet` помнит порядок добавления.
- `TreeSet` хранит элементы **отсортированными** и умеет находить крайние: `first()`, `last()`.

```java
Set<Integer> numbers = new TreeSet<>(List.of(5, 1, 3, 1));
System.out.println(numbers);   // [1, 3, 5]
```

```quiz
? Что выведет программа?
    Set<String> words = new TreeSet<>(List.of("вишня", "арбуз", "банан", "арбуз"));
    System.out.println(words);
- [вишня, арбуз, банан, арбуз]
- [вишня, арбуз, банан]
+ [арбуз, банан, вишня]
- [арбуз, арбуз, банан, вишня]
> `TreeSet` убирает повторы и сортирует элементы по алфавиту.
```

## Убираем дубликаты

Самый короткий способ убрать повторы из списка — передать его в конструктор множества:

```java
List<String> visits = List.of("Аня", "Боря", "Аня", "Вика", "Боря");
Set<String> unique = new LinkedHashSet<>(visits);   // [Аня, Боря, Вика]
```

## Операции над множествами

Как в математике, множества можно объединять, пересекать и вычитать. Эти методы **меняют** множество, поэтому сначала делают копию:

```java
Set<String> a = new TreeSet<>(List.of("Аня", "Боря", "Вика"));
Set<String> b = new TreeSet<>(List.of("Боря", "Гена"));

Set<String> union = new TreeSet<>(a);
union.addAll(b);            // объединение: [Аня, Боря, Вика, Гена]

Set<String> both = new TreeSet<>(a);
both.retainAll(b);          // пересечение: [Боря]

Set<String> onlyA = new TreeSet<>(a);
onlyA.removeAll(b);         // разность: [Аня, Вика]
```

## Какие элементы можно класть в множество

`HashSet` сравнивает элементы через `equals` и `hashCode`. У строк, чисел и записей (`record`) они уже написаны правильно. Для своих обычных классов их нужно переопределить — иначе два одинаковых по смыслу объекта будут считаться разными.
