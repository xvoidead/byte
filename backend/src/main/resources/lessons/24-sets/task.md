Учитель собрал списки учеников, решивших задачу A и задачу B. Первая строка ввода — имена решивших A через пробел, вторая — решивших B. Имена могут повторяться, строка может быть пустой.

Выведите, отсортировав имена по алфавиту:

```
Обе задачи: ...
Только A: ...
Только B: ...
Всего разных: N
```

Если в какой-то группе никого нет, вместо имён выведите «—».

Для ввода

```
Аня Боря Вика Аня
Боря Гена Вика
```

вывод:

```
Обе задачи: Боря Вика
Только A: Аня
Только B: Гена
Всего разных: 4
```

Используйте `TreeSet` и операции над множествами.
