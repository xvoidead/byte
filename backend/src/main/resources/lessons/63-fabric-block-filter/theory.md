Fabric сообщает о попытке сломать блок до того, как действие завершится. Callback `BEFORE` возвращает boolean: false запрещает ломание.

## Состояние и тип блока

Callback получает `BlockState`. В Minecraft тип проверяют через `state.isOf(Blocks.BEDROCK)`, а не сравнением текста названия.

```java
if (state.isOf(Blocks.BEDROCK)) {
    return false;
}
return true;
```

```quiz
? Что проверяет state.isOf(Blocks.BEDROCK)?
- Координату Y
+ Является ли блок бедроком
- Подключён ли игрок
> BlockState описывает блок, а isOf сравнивает его с конкретным Block.
```

## Возвращаем решение

Зарегистрируйте обработчик `PlayerBlockBreakEvents.BEFORE`. При запрете отправьте игроку сообщение и верните false. Для обычного блока верните true.

```quiz
? Какое значение разрешает продолжить ломание в BEFORE?
- false
+ true
- null
> Возвращаемое значение BEFORE управляет разрешением действия.
```

## Проверяем два случая

Проверьте как запрещённый блок, так и обычный. Если callback всегда возвращает false, игрок не сможет ломать вообще ничего.

Сценарий Fabric Byte: `break Steve x y z MATERIAL`. Он вызывает упрощённый callback, но не запускает игру.

```quiz

- Чтобы добавить новый listener

```
