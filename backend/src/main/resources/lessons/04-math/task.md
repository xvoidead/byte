Программа получает длины двух катетов прямоугольного треугольника — целые числа от 1 до 1000.

Выведите:

1. гипотенузу с двумя знаками после точки;
2. площадь с двумя знаками после точки;
3. периметр, округлённый до ближайшего целого с помощью `Math.round`.

Для ввода `3 4`:

```
Гипотенуза: 5.00
Площадь: 6.00
Периметр: 12
```

Будьте внимательны с делением: площадь треугольника с катетами 1 и 1 равна 0.50, а не 0.
