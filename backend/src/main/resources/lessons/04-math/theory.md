В школе 7 / 2 — это 3,5. В Java — не всегда. Разберёмся, как язык обращается с числами и какие инструменты для вычислений у него есть.

## Целые и дробные числа

Если оба числа в выражении целые, результат тоже будет целым — дробная часть просто отбрасывается:

```java
System.out.println(7 / 2);     // 3
System.out.println(7 / 2.0);   // 3.5
System.out.println(7.0 / 2);   // 3.5
```

Правило простое: если хотя бы одно число дробное (`double`), всё выражение вычисляется в дробных числах.

У `double` есть особенность: он хранит числа приближённо, поэтому иногда получаются «странные» хвосты:

```java
System.out.println(0.1 + 0.2); // 0.30000000000000004
```

Для денег и других точных расчётов такие числа не подходят — там обычно считают в копейках целыми числами.

## Приведение типов

Иногда нужно явно превратить значение одного типа в другой. Для этого перед значением пишут нужный тип в скобках:

```java
int a = 7;
int b = 2;
double exact = (double) a / b;  // 3.5 — a стало дробным до деления
int whole = (int) 3.99;         // 3 — дробная часть отбрасывается, а не округляется!
```

Из «меньшего» типа в «больший» Java преобразует сама: `int` → `long` → `double`. В обратную сторону — только явно, потому что можно потерять данные.

```quiz
? Что выведет программа?
    System.out.println((int) 7.9 + (int) -7.9);
+ 0
- 1
- 16
- -1
> Приведение к `int` отбрасывает дробную часть в сторону нуля: 7.9 → 7, −7.9 → −7. Сумма равна 0.
```

## Класс Math

В Java есть готовый набор математических функций — класс `Math`:

```java
Math.abs(-5)        // 5 — модуль
Math.max(3, 8)      // 8
Math.min(3, 8)      // 3
Math.pow(2, 10)     // 1024.0 — степень, результат double
Math.sqrt(16)       // 4.0 — квадратный корень
Math.hypot(3, 4)    // 5.0 — гипотенуза
Math.PI             // 3.141592653589793
```

Пример — расстояние между двумя точками на плоскости:

```java
double dx = x2 - x1;
double dy = y2 - y1;
double distance = Math.sqrt(dx * dx + dy * dy);
```

## Округление

| Метод | Что делает | 2.5 | −2.5 |
|-------|-----------|-----|------|
| `Math.round` | до ближайшего целого, половина — вверх | 3 | −2 |
| `Math.floor` | вниз | 2.0 | −3.0 |
| `Math.ceil` | вверх | 3.0 | −2.0 |
| `(int)` | к нулю | 2 | −2 |

`Math.round` возвращает `long`, а `floor` и `ceil` — `double`.

```quiz
? Что выведет программа?
    System.out.println(Math.round(2.5) + " " + Math.round(-2.5));
- 3 -3
+ 3 -2
- 2 -2
- 3.0 -2.0
> `Math.round` округляет половину в сторону большего числа: 2.5 → 3, а −2.5 → −2, потому что −2 больше, чем −3.
```

## Остаток от деления

Оператор `%` даёт остаток. С его помощью проверяют делимость:

```java
boolean even = n % 2 == 0;     // чётное ли число
int lastDigit = n % 10;        // последняя цифра
```

Для отрицательных чисел остаток тоже отрицательный: `-7 % 3` равно `-1`. Если нужен остаток «по кругу» от 0 до делителя, используйте `Math.floorMod(-7, 3)` — это `2`.

## Красивый вывод дробных

Чтобы вывести число с нужным количеством знаков после точки, используйте `printf`:

```java
import java.util.Locale;

double price = 1234.5;
System.out.printf(Locale.US, "Цена: %.2f%n", price); // Цена: 1234.50
```

`%.2f` — дробное число с двумя знаками, `%d` — целое, `%s` — строка, `%n` — перевод строки. `Locale.US` гарантирует точку в качестве разделителя.
