Напишите менеджер задач. Команды приходят по одной на строке до конца ввода:

| Команда | Действие |
|---------|---------|
| `add ТЕКСТ` | добавить задачу; вывести `Добавлена задача N` |
| `list` | вывести все задачи по возрастанию номеров: `N. [x] текст` для выполненных, `N. [ ] текст` для остальных; если задач нет — `Список пуст` |
| `done N` | отметить выполненной |
| `undo N` | снять отметку |
| `remove N` | удалить задачу; вывести `Удалена задача N` |
| `stats` | вывести `Выполнено: X из Y` |

Номера начинаются с 1 и не используются повторно. Если задачи с таким номером нет или номер — не число, выведите `Задача N не найдена` (где N — то, что ввёл пользователь), а если номер не указан — `Укажите номер задачи`. Пустой текст в `add` — ошибка: `Пустая задача`. Для неизвестной команды выведите `Неизвестная команда: КОМАНДА`.

Для ввода

```
add купить хлеб
add позвонить маме
done 1
list
remove 3
stats
```

вывод:

```
Добавлена задача 1
Добавлена задача 2
1. [x] купить хлеб
2. [ ] позвонить маме
Задача 3 не найдена
Выполнено: 1 из 2
```

Создайте класс `Task`.
