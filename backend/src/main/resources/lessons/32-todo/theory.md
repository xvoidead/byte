Последний проект курса — консольный менеджер задач. В нём соберётся почти всё, что вы изучили: классы и инкапсуляция, словари, разбор текстовых команд, аккуратная обработка ошибок.

## Что будем делать

Программа понимает команды:

```
add купить хлеб      — добавить задачу
list                 — показать все задачи
done 1               — отметить задачу выполненной
undo 1               — снять отметку
remove 2             — удалить задачу
stats                — сколько выполнено
```

Каждая задача получает номер, который не меняется, даже если другие задачи удалили.

## Модель данных

Задача — это объект с номером, текстом и признаком «выполнено». Номер и текст не меняются, а признак — меняется, поэтому здесь подойдёт обычный класс, а не `record`:

```java
class Task {
    private final int id;
    private final String title;
    private boolean done;

    Task(int id, String title) {
        this.id = id;
        this.title = title;
    }

    void markDone() {
        done = true;
    }

    // геттеры, undo и toString
}
```

## Хранилище

Задачи удобно хранить в словаре «номер → задача». Чтобы `list` показывал их по порядку номеров, подойдёт `TreeMap` (или `LinkedHashMap`, который помнит порядок добавления):

```java
Map<Integer, Task> tasks = new TreeMap<>();
int nextId = 1;

Task task = new Task(nextId++, "купить хлеб");
tasks.put(task.id(), task);
```

Счётчик `nextId` только растёт, поэтому номера удалённых задач не используются повторно.

```quiz
? Что выведет программа?
    Map<Integer, String> m = new LinkedHashMap<>();
    m.put(3, "c");
    m.put(1, "a");
    m.put(2, "b");
    System.out.println(m.keySet());
+ [3, 1, 2]
- [1, 2, 3]
- [c, a, b]
- Порядок не определён
> `LinkedHashMap` хранит ключи в порядке добавления. Отсортировал бы их `TreeMap`.
```

## Разбор команд

Команда — первое слово строки, а всё остальное — аргумент. Удобно разделить строку на две части методом `split` с ограничением:

```java
String[] parts = line.strip().split(" ", 2);
String command = parts[0];
String argument = parts.length > 1 ? parts[1] : "";
```

```quiz
? Что вернёт `"add купить хлеб".split(" ", 2)`?
- ["add", "купить", "хлеб"]
+ ["add", "купить хлеб"]
- ["add купить", "хлеб"]
- ["add"]
> Второй аргумент ограничивает число частей: строка делится только по первому пробелу, остаток идёт одним куском.
```

## Номера и ошибки

Аргумент команд `done`, `undo` и `remove` — номер задачи. Пользователь может ввести несуществующий номер или вообще не число. Программа должна ответить понятным сообщением, а не упасть. Здесь пригодится всё из уроков про исключения.
