Программа получает одну строку текста. Выведите:

1. её длину;
2. строку задом наперёд;
3. является ли она **палиндромом** — читается ли одинаково в обе стороны, **без учёта регистра и пробелов**.

Пример для `шалаш`:

```
Длина: 5
Наоборот: шалаш
Палиндром: да
```

Для `Java`:

```
Длина: 4
Наоборот: avaJ
Палиндром: нет
```

Фраза «А роза упала на лапу Азора» — тоже палиндром.
