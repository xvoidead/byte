Проанализируйте продажи кафе. Каждая строка ввода — товар, цена и количество через пробел. Код чтения уже написан: он превращает строки в список записей `Sale`.

Выведите:

1. общую выручку (сумма цен, умноженных на количество);
2. самый дорогой товар по цене за штуку (если таких несколько — первый во вводе);
3. сколько продаж было с ценой больше 1000;
4. список разных товаров по алфавиту через запятую.

Для ввода

```
кофе 250 3
чай 180 2
торт 1200 1
кофе 250 1
```

вывод:

```
Выручка: 2560
Самый дорогой товар: торт
Продаж дороже 1000: 1
Товары: кофе, торт, чай
```

Решите задачу потоками — без циклов `for` и `while`.
