Напишите мини-банк с понятными сообщениями об ошибках. Команды приходят по одной на строке до конца ввода:

- `open ИМЯ` — открыть счёт с нулевым балансом;
- `deposit ИМЯ СУММА` — пополнить;
- `withdraw ИМЯ СУММА` — снять;
- `transfer ОТКУДА КУДА СУММА` — перевести;
- `balance ИМЯ` — вывести `ИМЯ: баланс`.

При ошибке команда не меняет балансы, а программа выводит `Ошибка: ` и текст:

- «сумма должна быть положительной» — сумма меньше или равна нулю (проверяется первой);
- «счёт ИМЯ не найден» — нет такого счёта (для перевода сначала проверяется отправитель, потом получатель);
- «недостаточно средств на счёте ИМЯ»;
- «счёт ИМЯ уже существует».

Класс `BankException` уже объявлен. Создайте от него `AccountNotFoundException` и `InsufficientFundsException` и бросайте их (а также сам `BankException`) из методов класса `Bank`. Главный цикл ловит `BankException` и печатает сообщение.

Для ввода

```
open Аня
open Боря
deposit Аня 500
transfer Аня Боря 200
balance Аня
balance Боря
withdraw Боря 300
balance Вика
```

вывод:

```
Аня: 300
Боря: 200
Ошибка: недостаточно средств на счёте Боря
Ошибка: счёт Вика не найден
```
