Сделайте систему скидок. Интерфейс `Discount` с методами `int apply(int price)` и `String describe()` уже объявлен. Реализуйте его в трёх классах:

- `PercentDiscount(p)` — скидка `p` процентов: цена уменьшается на `price * p / 100` (целочисленно), описание «Скидка p%»;
- `FixedDiscount(x)` — скидка `x` рублей, но цена не может стать меньше нуля, описание «Скидка x ₽»;
- `NoDiscount` — цена не меняется, описание «Без скидки».

Первая строка ввода — цена, дальше до конца ввода — скидки: `percent p`, `fixed x` или `none`. Код чтения уже написан: он выводит описание и цену со скидкой, а в конце — лучшую цену.

Для ввода

```
1000
percent 10
fixed 300
none
```

вывод:

```
Скидка 10%: 900
Скидка 300 ₽: 700
Без скидки: 1000
Лучшая цена: 700
```
