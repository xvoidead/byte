**Интерфейс** описывает, что объект умеет делать, но не говорит как. Это контракт: класс, который реализует интерфейс, обещает предоставить все его методы.

## Объявление интерфейса

```java
interface Greeter {
    String greet(String name);
}

class FormalGreeter implements Greeter {
    @Override
    public String greet(String name) {
        return "Здравствуйте, " + name + "!";
    }
}

class FriendlyGreeter implements Greeter {
    @Override
    public String greet(String name) {
        return "Привет, " + name + "!";
    }
}
```

Методы интерфейса по умолчанию публичные и абстрактные, поэтому в классе их реализуют с модификатором `public`.

## Полиморфизм

Код, который работает с интерфейсом, не знает и не должен знать, какой именно класс ему достался:

```java
List<Greeter> greeters = List.of(new FormalGreeter(), new FriendlyGreeter());
for (Greeter g : greeters) {
    System.out.println(g.greet("Аня"));
}
```

Можно добавить новый вид приветствия, не меняя этот цикл. Так строят гибкие программы: платёжные системы, плагины, игровых персонажей.

## Методы по умолчанию

Интерфейс может содержать методы с реализацией — они помечаются словом `default`:

```quiz
? Что выведет программа?
    interface Named {
        String name();

        default String hello() {
            return "Привет, " + name();
        }
    }
    class Robot implements Named {
        public String name() {
            return "R2";
        }
    }
    public class Main {
        public static void main(String[] args) {
            System.out.println(new Robot().hello());
        }
    }
+ Привет, R2
- Привет, null
- Ошибка компиляции: Robot не реализует hello
- R2
> `hello()` — метод по умолчанию: он уже реализован в интерфейсе и вызывает `name()`, который дал класс `Robot`.
```

## Интерфейс или абстрактный класс

| | Интерфейс | Абстрактный класс |
|---|---|---|
| Сколько можно унаследовать | сколько угодно | только один |
| Поля с состоянием | нет | есть |
| Конструкторы | нет | есть |
| Когда использовать | «умеет делать» | «является разновидностью» |

Класс может одновременно наследоваться от одного класса и реализовывать несколько интерфейсов:

```java
class Duck extends Animal implements Swimmer, Flyer { ... }
```

```quiz
? Сколько интерфейсов может реализовать один класс?
- Только один
- Не больше двух
+ Сколько угодно
- Ни одного, если у класса есть родитель
> Наследоваться можно только от одного класса, а интерфейсов — сколько угодно: `implements A, B, C`.
```

## Интерфейсы из стандартной библиотеки

Вы уже пользовались интерфейсами: `List` — это интерфейс, а `ArrayList` и `LinkedList` — его реализации. Поэтому хорошая практика — объявлять переменную типом интерфейса:

```java
List<String> names = new ArrayList<>();   // легко заменить на LinkedList
```

Ещё один знаменитый интерфейс — `Comparable`: его реализуют классы, которые умеют сравниваться между собой, например `String` и `Integer`.
