Сделайте калькулятор с таблицей операций. Первая строка ввода — два целых числа `a` и `b` (`a` от −100 до 100, `b` от 0 до 9). Дальше до конца ввода — названия операций по одному на строке.

Операции:

| Название | Результат |
|----------|-----------|
| `add` | a + b |
| `sub` | a − b |
| `mul` | a · b |
| `max` | большее из чисел |
| `min` | меньшее из чисел |
| `pow` | a в степени b (целое число) |

Для каждой операции выведите `название: результат`, а для неизвестной — `название: неизвестная операция`.

Для ввода

```
3 4
add
pow
foo
```

вывод:

```
add: 7
pow: 81
foo: неизвестная операция
```

Храните операции в `Map<String, BinaryOperator<Long>>` с лямбдами — без `switch`.
