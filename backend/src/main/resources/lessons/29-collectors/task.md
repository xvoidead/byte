Составьте сводку по школьному журналу. Каждая строка ввода — предмет, имя ученика и оценка (от 2 до 5). Код чтения уже написан: он превращает строки в список записей `Grade`.

Для каждого предмета (по алфавиту) выведите средний балл с двумя знаками и лучшего ученика — с наибольшей оценкой, а при равенстве оценок — первого по алфавиту:

```
Предмет: средний X.XX, лучший — Имя (оценка)
```

В конце выведите, сколько учеников — отличники, то есть имеют только пятёрки по всем своим оценкам.

Для ввода

```
Математика Аня 5
Математика Боря 4
Физика Аня 5
Физика Вика 3
Математика Вика 5
```

вывод:

```
Математика: средний 4.67, лучший — Аня (5)
Физика: средний 4.00, лучший — Аня (5)
Отличников: 1
```

Используйте `Collectors.groupingBy`.
