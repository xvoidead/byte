Соберите небольшой плагин экономики. При входе игрок получает начальный баланс 0. За сломанный блок начисляется награда из `rewards.<MATERIAL>` в `config.yml`; для неуказанного блока награда равна 0.

Реализуйте команды:

- `/balance` — показать свой баланс;
- `/pay <игрок> <сумма>` — перевести монеты онлайн-игроку; сумма должна быть положительной, денег должно хватать;
- `/baltop` — показать игроков онлайн по балансу по убыванию, при равенстве — по имени.

Сообщения должны совпадать с примерами. Экономика хранится в памяти до перезапуска сервера. Награды настраиваются через YAML, а состояние игрока — в коллекции.
