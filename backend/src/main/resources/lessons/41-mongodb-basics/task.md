Сделайте хранилище профилей игроков в MongoDB. Профиль — документ `{name, level, coins, items}`, новый игрок начинает с уровнем 1, без монет и предметов. Команды `join` и `profile` уже работают, допишите остальные:

| Команда | Ответ |
|---------|-------|
| `join <имя>` | `Новый игрок: <имя>` или `С возвращением, <имя>!` |
| `reward <имя> <монеты>` | `<имя> получает <монеты> монет` |
| `give <имя> <предмет>` | `<имя> получает <предмет>` или, если предмет уже есть, `У <имя> уже есть <предмет>` |
| `levelup <имя>` | `<имя> теперь уровня <уровень>` |
| `profile <имя>` | `<имя>: уровень 2, монет 50, предметы: меч, лук` (или `предметов нет`) |
| `top` | до трёх строк `1. <имя> — уровень 2, монет 50`: по уровню, при равенстве — по монетам (больше выше), затем по имени; если игроков нет — `Игроков нет` |
| `rich <монеты>` | `Богачи: Alex, Steve` — у кого монет не меньше заданного, по имени; или `Богачей нет` |

Если игрока нет, команды `reward`, `give`, `levelup` и `profile` отвечают `Нет игрока <имя>`.

Все изменения делайте в базе: `updateOne` с `Updates`, для `levelup` — `findOneAndUpdate`, чтобы сразу узнать новый уровень. Сортируйте и фильтруйте запросами, а не в Java.
