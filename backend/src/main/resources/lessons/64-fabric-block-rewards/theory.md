Событие `AFTER` вызывается после успешного действия. Его удобно использовать для наград и статистики.

## Слушаем успешное ломание

`PlayerBlockBreakEvents.AFTER` получает игрока, координаты и `BlockState`. Если действие запрещено через BEFORE, AFTER не вызывается.

```java
PlayerBlockBreakEvents.AFTER.register((world, player, pos, state, blockEntity) -> {
    // награда за действительно добытый блок
});
```

```quiz
? Когда приходит событие AFTER?
- До проверки разрешения
+ После успешного ломания
- Только при входе игрока
> AFTER предназначен для последствий выполненного действия.
```

## Выбираем награду

Для каждого типа блока можно выбрать своё число очков через `isOf`:

```java
int reward = state.isOf(Blocks.DIAMOND_ORE) ? 5 : 1;
```

Отфильтруйте материалы, за которые очки не выдаются. Так земля не получит случайную награду.

```quiz
? Сколько очков начисляет пример для DIAMOND_ORE?
- 1
+ 5
- 0 всегда
> Тернарное выражение выбирает пять для алмазной руды.
```

## Суммируем по игроку

Сохраните счёт в `Map<String, Integer>` по имени игрока или используйте UUID в реальном проекте. `merge` складывает награду и существующее значение. После обновления покажите новое общее число.

```quiz
? Что даст merge для прежних 2 очков и награды 5?
- 5
+ 7
- 25
> Функция Integer::sum складывает оба значения.
```
