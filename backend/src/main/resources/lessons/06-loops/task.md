Классическая задача **FizzBuzz**. Программа получает число `n`. Выведите числа от 1 до `n`, каждое на новой строке, но:

- вместо чисел, кратных 3, выведите `Fizz`;
- вместо чисел, кратных 5, — `Buzz`;
- вместо чисел, кратных и 3, и 5, — `FizzBuzz`.

Например, для `n = 5`:

```
1
2
Fizz
4
Buzz
```

Подсказка: число `x` кратно `k`, если `x % k == 0`. Подумайте, в каком порядке проверять условия.
