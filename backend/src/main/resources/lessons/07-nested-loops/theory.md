Цикл может находиться внутри другого цикла. Так обрабатывают всё, что устроено как таблица: строки и столбцы, дни и часы, клетки игрового поля.

## Цикл в цикле

Таблица умножения 3 × 3:

```java
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        System.out.print(i * j + "\t");
    }
    System.out.println();
}
```

```
1	2	3
2	4	6
3	6	9
```

Главное правило: **при каждом шаге внешнего цикла внутренний проходит полностью**. Если внешний цикл делает `n` шагов, а внутренний — `m`, тело внутреннего выполнится `n · m` раз.

`\t` — символ табуляции, он выравнивает столбцы.

```quiz
? Что выведет программа?
    for (int i = 1; i <= 3; i++) {
        for (int j = 1; j <= i; j++) {
            System.out.print(j);
        }
        System.out.println();
    }
+ 1\n12\n123
- 123\n123\n123
- 1\n2\n3
- 111\n22\n3
> Граница внутреннего цикла зависит от `i`: в первой строке он делает один шаг, во второй — два, в третьей — три.
```

## Рисуем фигуры

Прямоугольник из звёздочек 3 × 5:

```java
for (int row = 0; row < 3; row++) {
    for (int col = 0; col < 5; col++) {
        System.out.print('*');
    }
    System.out.println();
}
```

Прямоугольный треугольник получается, если длина строки зависит от её номера:

```java
for (int row = 1; row <= 4; row++) {
    for (int col = 0; col < row; col++) {
        System.out.print('*');
    }
    System.out.println();
}
```

```
*
**
***
****
```

## Отступы и выравнивание

Чтобы фигура стояла «по центру», перед звёздочками печатают пробелы. Например, для пирамиды высотой `n` в строке номер `row` нужно `n - row` пробелов и `2 * row - 1` звёздочек:

```
   *
  ***
 *****
*******
```

Такие задачи удобно решать так: сначала на бумаге выписать, сколько пробелов и символов в каждой строке, а потом найти формулу.

```quiz
? Внешний цикл делает 10 шагов, внутренний — 20. Сколько раз выполнится тело внутреннего цикла?
- 30
- 20
+ 200
- 10
> При каждом из 10 шагов внешнего цикла внутренний проходит все 20 шагов: 10 · 20 = 200.
```

## break во вложенных циклах

`break` прерывает только **тот цикл, в котором находится**. Внешний цикл после этого продолжит работу:

```java
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (j == 2) {
            break; // выходим только из внутреннего цикла
        }
        System.out.println(i + " " + j);
    }
}
// напечатает 1 1, 2 1, 3 1
```

Чтобы выйти сразу из двух циклов, используют метку: `outer: for (...) { ... break outer; }` — но чаще проще вынести вложенные циклы в отдельный метод и сделать `return`.
