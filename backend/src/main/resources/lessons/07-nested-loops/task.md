Нарисуйте ёлочку. Программа получает высоту `n` (от 1 до 20). Выведите пирамиду из `n` строк из символов `*`, выровненную по центру пробелами, а под ней — ствол `|` ровно под вершиной.

Для `n = 3`:

```
  *
 ***
*****
  |
```

Для `n = 1`:

```
*
|
```

Пробелы в конце строк не нужны. Рисуйте ёлочку вложенными циклами, не используя `String.repeat`.
