Сделайте таблицу рекордов мини-игры. Программа уже читает результаты партий (строки `имя очки`) и сохраняет их в таблицу `results` базы `game.db`. Допишите отчёт — все числа посчитайте SQL-запросами:

```
Игр: 6
Игроков: 3
Рекорд: 120 (Alex)
Лучшие игроки:
1. Alex — 120
2. Steve — 95
3. Notch — 80
```

- **Игр** — сколько всего строк в таблице.
- **Игроков** — сколько разных имён.
- **Рекорд** — самый большой счёт и кто его набрал. Если рекорд поставили несколько игроков, покажите первого по алфавиту.
- **Лучшие игроки** — не больше трёх игроков с самым большим *личным* рекордом. При равных очках выше тот, чьё имя раньше по алфавиту.

Если партий нет, выведите:

```
Игр: 0
Игроков: 0
Рекордов пока нет
```

Сортируйте и выбирайте строки в SQL (`ORDER BY`, `LIMIT`, `GROUP BY`), а не в Java.
