Допишите класс `BankAccount` — банковский счёт с приватным полем `balance`.

Методы:

- `deposit(int amount)` — пополняет счёт;
- `withdraw(int amount)` — снимает деньги; если денег не хватает, печатает `Недостаточно средств` и баланс не меняет;
- `getBalance()` — возвращает текущий баланс.

Если в `deposit` или `withdraw` передана сумма меньше или равная нулю, нужно напечатать `Сумма должна быть положительной` и ничего не делать.

Метод `main` уже написан: он читает команды `deposit N`, `withdraw N` и `balance` и вызывает методы счёта.

Пример ввода:

```
deposit 50
withdraw 80
balance
```

Вывод:

```
Недостаточно средств
Баланс: 50
```
