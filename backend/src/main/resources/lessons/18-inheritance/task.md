Допишите иерархию фигур. Абстрактный класс `Shape` с методами `area()` и `name()` уже объявлен.

Создайте:

- `Circle extends Shape` — круг с радиусом, имя «Круг»;
- `Rectangle extends Shape` — прямоугольник со сторонами, имя «Прямоугольник»;
- `Square extends Rectangle` — квадрат: это прямоугольник с равными сторонами, имя «Квадрат».

Программа читает фигуры до конца ввода — по одной на строке: `circle r`, `rectangle w h` или `square a` (целые числа). Код чтения уже написан. Для каждой фигуры выводится её имя и площадь с двумя знаками после точки, а в конце — общая площадь.

Для ввода

```
circle 1
rectangle 2 3
square 4
```

вывод:

```
Круг: 3.14
Прямоугольник: 6.00
Квадрат: 16.00
Общая площадь: 25.14
```
