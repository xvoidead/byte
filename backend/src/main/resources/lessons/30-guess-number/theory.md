Пора собрать всё изученное в настоящую программу. Напишем игру: компьютер загадывает число от 1 до 100, а игрок пытается угадать, получая подсказки «больше» или «меньше».

В этом уроке пригодятся ввод с клавиатуры, циклы, условия и обработка ошибок. Готовую игру можно запустить в интерактивной консоли и сыграть самому.

## Случайные числа

Случайные числа выдаёт класс `Random`:

```java
Random random = new Random();
int dice = random.nextInt(6) + 1;     // от 1 до 6
```

`nextInt(n)` возвращает число от 0 до `n − 1`. Поэтому для диапазона от 1 до 100 пишут `nextInt(100) + 1`.

```quiz
? Какие значения может вернуть `random.nextInt(100)`?
- От 1 до 100
+ От 0 до 99
- От 0 до 100
- Любые целые числа
> Граница не включается: `nextInt(100)` даёт числа от 0 до 99. Чтобы получить от 1 до 100, прибавьте единицу.
```

## Воспроизводимая случайность

Если передать в `Random` число — **зерно** (seed), — последовательность «случайных» чисел будет каждый раз одной и той же. Это полезно для тестов и для игр, где можно поделиться «сидом» уровня:

```quiz
? Что выведет программа?
    Random r = new Random(42);
    System.out.println(r.nextInt(10) + " " + r.nextInt(10));
+ 0 3
- 4 2
- 42 42
- Каждый запуск по-разному
> С одинаковым зерном генератор всегда выдаёт одну и ту же последовательность. Для зерна 42 первые два числа — 0 и 3.
```

## Игровой цикл

Сердце игры — цикл, который повторяется, пока игра не закончена:

```java
while (!finished && in.hasNextLine()) {
    String line = in.nextLine();
    // разобрать ввод, сравнить с загаданным, вывести подсказку
}
```

`hasNextLine()` защищает от ситуации, когда игрок закрыл ввод (Ctrl + D), не дойдя до конца.

## Проверка ввода

Игрок может ввести что угодно: буквы, пустую строку, число 500. Хорошая программа не падает, а вежливо просит повторить:

```java
int guess;
try {
    guess = Integer.parseInt(line.trim());
} catch (NumberFormatException e) {
    System.out.println("Введите число от 1 до 100");
    continue;
}
if (guess < 1 || guess > 100) {
    System.out.println("Введите число от 1 до 100");
    continue;
}
```

`continue` переходит к следующему шагу цикла, не выполняя остальную часть тела.

## Ограничение попыток

Двоичный поиск из урока 12 подсказывает, что любое число от 1 до 100 можно угадать не больше чем за 7 попыток: 2⁷ = 128 > 100. Поэтому 7 попыток — честное ограничение: хорошая стратегия всегда успевает.

## Как проверить себя

Запустите игру в консоли и сыграйте. Потом попробуйте сломать её: введите текст, пустую строку, 0, 101, завершите ввод раньше времени. Каждая такая проверка — это тест, который вы сделали руками.
