Сделайте плагин, который берёт сообщения из `config.yml`:

- `prefix` — префикс, например `[Byte]`;
- `welcome` — шаблон приветствия с `%player%`;
- `motd` — список строк для команды `/info`.

При входе выведите `<prefix> <welcome с именем>`. Команда `/info` печатает каждую строку MOTD с тем же префиксом. В пустом списке MOTD ничего не выводите. В проекте есть встроенный `resources/config.yml` с настройками по умолчанию; тесты подменяют рабочий `config.yml`, чтобы убедиться, что код действительно читает файл.
