Посчитайте статистику по списку чисел, который ввёл неаккуратный пользователь.

Каждая строка ввода должна содержать одно целое число (пробелы по краям допустимы). Пустые строки пропускайте. Строки, которые не удаётся превратить в `int` (буквы, дробные числа, слишком большие числа), считайте ошибками и тоже пропускайте.

Выведите сумму, количество чисел, количество ошибок и среднее с двумя знаками после точки. Если чисел нет, вместо среднего выведите «нет данных».

Для ввода

```
10
20
абв
30
```

вывод:

```
Сумма: 60
Чисел: 3
Ошибок: 1
Среднее: 20.00
```

Для превращения строки в число используйте `Integer.parseInt` и обработку исключения.
