У Bukkit есть готовая проверка оператора (`isOp()`), но реальные плагины обычно вводят именованные разрешения. Так администратор может выдать право на одну команду, не делая игрока оператором.

## Объявляем право

Разрешения и команды записываются в `resources/plugin.yml`. Строка `default: op` означает, что право автоматически получают операторы; `default: false` — никто не получает его автоматически.

```yaml
permissions:
  byte.announce:
    description: Разрешает отправлять объявления
    default: op
```

Имя — строковый ключ. Используйте свой префикс (`byte.`), чтобы случайно не пересечься с правами других плагинов.

```quiz
? Кто по умолчанию получает byte.announce при default: op?
+ Только операторы
- Все игроки
- Только консоль
> Значение op включает разрешение для оператора сервера.
```

## Проверяем право в команде

Объявите команду в том же `plugin.yml`, затем подключите `CommandExecutor`. Внутри обработчика проверьте отправителя:

```java
if (!sender.hasPermission("byte.announce")) {
    sender.sendMessage("Недостаточно прав.");
    return true;
}
```

Проверка в коде обязательна: она защищает команду даже тогда, когда настройки команды изменятся. Права можно выдавать точечно через permission-плагины.

```quiz
? Что делает sender.hasPermission("byte.announce")?
- Выдаёт игроку право
+ Проверяет, есть ли у отправителя это право
- Делает отправителя оператором
> Метод отвечает true или false; он не меняет настройки доступа.
```

## Собираем текст объявления

`args` содержит слова после команды. Если сообщение состоит из нескольких слов, склейте их через `String.join(" ", args)`. Для рассылки используйте `getServer().broadcastMessage(...)`.

Сначала проверяйте право, затем наличие текста. Такой порядок не раскрывает подробности команды тем, у кого нет доступа.

```quiz
? Как собрать args = ["Сервер", "готов"] в одну фразу?
- Arrays.toString(args)
+ String.join(" ", args)
- args[0] + args[1] без пробела
> String.join вставляет указанный разделитель между всеми словами.
```
