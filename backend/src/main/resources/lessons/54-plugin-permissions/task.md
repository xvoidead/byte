Добавьте команду `/announce`. Право `byte.announce` должно по умолчанию быть только у операторов. Без права отправитель видит `Недостаточно прав.`; с правом текст объявления рассылается всем онлайн-игрокам с префиксом `[Объявление]`.

Проверяйте право в обработчике команды через `hasPermission`, а не только скрывайте команду в `plugin.yml`. Сценарий понимает `join`, `op`, `deop` и `cmd`.
