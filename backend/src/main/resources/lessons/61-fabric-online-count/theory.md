После события JOIN можно прочитать список подключённых игроков и показать всем обновлённое число.

## Получаем список игроков

В callback передаётся `MinecraftServer`. Игроков обслуживает `server.getPlayerManager()`, а `getPlayerList()` возвращает список подключённых серверных игроков.

```java
int count = server.getPlayerManager().getPlayerList().size();
```

В учебном runtime игрок добавляется в список перед вызовом JOIN, поэтому число включает нового участника.

```quiz
? Что возвращает getPlayerList()?
- Список всех игроков, которые когда-либо заходили
+ Текущих подключённых игроков
- Список модов
> PlayerManager хранит текущий список игроков сервера.
```

## Объявляем всем

`PlayerManager.broadcast(Text, false)` отправляет компонент всем онлайн-игрокам. Сначала постройте сообщение, затем передайте его в broadcast.

```quiz
? Кому отправит сообщение PlayerManager.broadcast(...)?
- Только автору мода
+ Онлайн-игрокам
- Всем игрокам Minecraft вне сервера
> Это серверная рассылка подключённым игрокам.
```

## Следим за моментом события

События описывают порядок действий. JOIN срабатывает после добавления игрока в этот учебный список, поэтому подсчёт видит новое значение. Для вывода числа на момент выхода нужно учитывать момент, когда конкретная версия Fabric удаляет игрока из списка.

```quiz
? Почему сообщение после JOIN уже включает вошедшего игрока?
- Callback сам добавляет его дважды
+ Runtime вызывает событие после добавления игрока в список
- Размер списка всегда равен 1
> Порядок событий определяет, какое состояние вы увидите.
```
