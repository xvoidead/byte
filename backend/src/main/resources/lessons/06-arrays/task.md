Первая строка ввода — количество чисел `n` (от 1 до 1000), вторая — сами `n` целых чисел.

Сохраните числа в массив и выведите максимум, минимум и среднее арифметическое с двумя знаками после точки:

```
Максимум: 8
Минимум: -2
Среднее: 3.40
```

Не используйте `Arrays.sort` — найдите максимум и минимум одним проходом по массиву.
