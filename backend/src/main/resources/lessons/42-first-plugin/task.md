Напишите первый плагин для Paper/Bukkit. При входе игрок должен получить три строки:

- `Добро пожаловать, <имя>!`
- `Это ваш первый вход.` — если этот игрок ещё не заходил с момента запуска плагина; иначе `С возвращением.`
- `Сейчас на сервере: N` — число игроков онлайн **включая вошедшего**.

При выходе не показывайте стандартное сообщение Bukkit. Стартовый проект уже содержит `Main.java`: он поднимает MockBukkit, загружает ваш плагин и исполняет сценарий из примера. `resources/plugin.yml` связывает имя плагина с главным Java-классом.

Проверить можно сценарием `join Steve`, `quit Steve`, `join Steve`. Событие `PlayerJoinEvent` срабатывает после входа, а `PlayerQuitEvent` — при выходе.
