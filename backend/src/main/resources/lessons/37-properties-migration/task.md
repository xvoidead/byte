Формат `server.properties` менялся от версии к версии:

| Версия | Что изменилось |
|--------|----------------|
| 1 | ключи `name`, `slots`, `pvp=yes/no`, поля `config-version` нет |
| 2 | `name` → `server-name`, `slots` → `max-players` |
| 3 | `pvp` стал `true`/`false` (`yes` → `true`, всё остальное или отсутствие → `false`), добавлен `view-distance=10`, если его нет |

Программа знает версию 3. Что нужно сделать:

1. Если файла нет, выведите `Нет файла server.properties`.
2. Прочитайте версию из `config-version`. Если ключа нет, это версия 1. Если там не целое число больше 0, выведите `config-version должен быть целым числом больше 0`. Если версия больше 3, выведите `Версия конфига 5 новее программы (3)`. В обоих случаях файл не трогайте.
3. Если версия меньше 3, примените миграции по очереди и перед каждой выведите `Миграция 1 → 2`. Затем запишите `config-version=3`, сохраните файл методом `save` и выведите `Конфиг обновлён до версии 3`. Остальные ключи, в том числе незнакомые, сохраните.
4. Если версия уже 3, выведите `Конфиг актуален (версия 3)` и не перезаписывайте файл.
5. В конце выведите `Сервер: Byte Craft, мест: 20, PvP: да, дальность: 10`.

Для старого конфига из проекта вывод такой:

```
Миграция 1 → 2
Миграция 2 → 3
Конфиг обновлён до версии 3
Сервер: Byte Craft, мест: 20, PvP: да, дальность: 10
```

Названия серверов бывают на русском, поэтому читайте файл в UTF-8.
