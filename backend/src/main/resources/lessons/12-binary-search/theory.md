Как найти число в массиве? Самый простой способ — перебрать все элементы. Но если массив отсортирован, можно искать несравнимо быстрее.

## Линейный поиск

Проходим по массиву, пока не встретим нужное значение:

```java
static int indexOf(int[] a, int target) {
    for (int i = 0; i < a.length; i++) {
        if (a[i] == target) {
            return i;
        }
    }
    return -1; // не нашли
}
```

В худшем случае придётся проверить все элементы: для миллиона — миллион сравнений.

## Двоичный поиск

Так ищут слово в бумажном словаре: открываем середину, смотрим, левее или правее нужное слово, и отбрасываем половину. Условие одно — **массив должен быть отсортирован**.

```java
static int binarySearch(int[] a, int target) {
    int left = 0;
    int right = a.length - 1;
    while (left <= right) {
        int mid = (left + right) / 2;
        if (a[mid] == target) {
            return mid;
        } else if (a[mid] < target) {
            left = mid + 1;   // искомое правее середины
        } else {
            right = mid - 1;  // искомое левее середины
        }
    }
    return -1;
}
```

Переменные `left` и `right` — границы участка, где ещё может быть ответ. Каждый шаг уменьшает участок вдвое.

## Почему это быстро

Каждый шаг делит область поиска пополам. Из миллиона элементов после 20 делений остаётся один: 2²⁰ ≈ 1 000 000. Поэтому двоичный поиск найдёт число среди миллиона не больше чем за 20 шагов.

## Ловушка с серединой

Для огромных массивов `(left + right) / 2` может переполнить `int`. Надёжнее писать `left + (right - left) / 2` — результат тот же, а переполнения нет. Эту ошибку много лет не замечали даже в стандартной библиотеке Java.

## Готовый метод

```java
int[] a = {1, 3, 5, 7};
Arrays.binarySearch(a, 5);   // 2
```

Если элемента нет, готовый метод вернёт отрицательное число, из которого можно понять, куда элемент нужно вставить.
