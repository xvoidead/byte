Напишите двоичный поиск и посчитайте, сколько шагов он делает.

Формат ввода:

- первая строка — `n` (от 1 до 1000);
- вторая — `n` **разных** чисел по возрастанию;
- третья — количество запросов `q`;
- четвёртая — `q` чисел, которые нужно найти.

Для каждого запроса выполните двоичный поиск строго по алгоритму из теории: `mid = (left + right) / 2`; если `a[mid]` равно искомому — остановитесь; если меньше — `left = mid + 1`; если больше — `right = mid - 1`. Шагом считается каждое сравнение с `a[mid]`, то есть каждая итерация цикла.

Выведите для каждого запроса строку `x: индекс i, шагов k` или `x: не найдено, шагов k`.

Для ввода

```
7
1 3 5 7 9 11 13
3
5 7 4
```

вывод:

```
5: индекс 2, шагов 3
7: индекс 3, шагов 1
4: не найдено, шагов 3
```

Готовые методы поиска использовать нельзя.
