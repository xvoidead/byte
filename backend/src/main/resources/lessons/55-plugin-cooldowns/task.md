Сделайте команду `/gift`. Первый вызов отвечает `Подарок получен!`; следующие вызовы того же игрока в течение пяти тиков — `Подождите перед новым подарком.`. После пяти тиков команду можно использовать снова. У каждого игрока свой cooldown. Используйте `UUID`, `Set` и `BukkitRunnable.runTaskLater`.
