## Счётчик на игрока

Создайте `Map<UUID, Integer>`. При входе добавьте игрока со значением 0 через `putIfAbsent`, чтобы случайно не перезаписать старую статистику.

```quiz
? Что делает putIfAbsent для уже известного UUID?
- Сбрасывает счёт
+ Оставляет старое значение
- Удаляет запись
> Значение добавляется только при отсутствии ключа.
```

## Обновляем событие

В обработчике `BlockBreakEvent` проверьте `Material.STONE`, затем увеличьте счётчик: `blocks.merge(uuid, 1, Integer::sum)`. Другой материал не меняет значение.

```quiz
? На сколько увеличится счёт после одного блока STONE?
- На ноль
+ На один
- На число игроков
> merge добавит 1 к текущему значению.
```

## Показываем статистику

Команда `/blocks` читает `blocks.getOrDefault(uuid, 0)`. Значение по умолчанию позволяет безопасно показать ноль игроку без добытых блоков. UUID надёжнее имени, которое может измениться.

```quiz
? Что вернёт getOrDefault(id, 0) для отсутствующего ключа?
- null
+ 0
- 1 всегда
> Второй аргумент используется, если ключа нет.
```
