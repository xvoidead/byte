# byte

Сайт, на котором можно изучать Java с работающей IDE прямо в браузере: короткие уроки, редактор уровня VS Code, настоящий компилятор и задания с автоматической проверкой.

## Возможности

- **10 уроков** — от «Hello, World» до коллекций: теория, задание, стартовый код и тесты.
- **Редактор Monaco** (тот же, что в VS Code): подсветка Java, автодополнение классов с автоматическим `import`, сниппеты в стиле IntelliJ (`sout`, `psvm`, `fori`, `foreach`…), `Ctrl+Enter` — запуск, `Ctrl+Shift+Enter` — проверка.
- **Настоящая Java 21**: код компилируется `javac` и выполняется на JVM.
- **Ошибки прямо в коде**: подчёркивание нужного места, список ошибок с переходом к строке и **пояснениями на русском** для частых ошибок компиляции и исключений.
- **Ввод с клавиатуры**: вкладка «Ввод» передаёт данные в `System.in`.
- **Автопроверка**: открытые тесты показывают ожидаемый и полученный вывод, данные скрытых тестов не раскрываются.
- **Прогресс и черновики** сохраняются в браузере.
- **Песочница** для свободных экспериментов.
- Адаптивная вёрстка — работает и с телефона.

## Архитектура

```
frontend/  React + TypeScript + Vite + Monaco Editor
backend/   Spring Boot 4 + Java 21
```

**Бэкенд** (`backend/src/main/java/dev/byteide`):

| Пакет | Что делает |
|-------|------------|
| `runner` | `JavaCompilationService` компилирует исходник встроенным `javac` (`javax.tools`) и находит класс с `main`; `ProcessExecutionService` запускает программу в отдельной JVM с ограничениями; `CodeRunner` объединяет шаги и ограничивает число одновременных запусков. |
| `lessons` | Загрузка уроков из `resources/lessons`, проверка решений на тестах. |
| `web` | REST API и отдача SPA. |

**API**

| Метод | Путь | Описание |
|-------|------|----------|
| `GET` | `/api/lessons` | Список уроков |
| `GET` | `/api/lessons/{slug}` | Урок: теория, задание, стартовый код, открытые примеры |
| `POST` | `/api/lessons/{slug}/check` | `{ "code" }` → результаты тестов |
| `POST` | `/api/run` | `{ "code", "stdin" }` → вывод, ошибки, диагностика компилятора |

## Запуск для разработки

Нужны JDK 21+ (именно JDK, не JRE), Maven 3.9+ и Node.js 22+.

```bash
# Терминал 1 — бэкенд на :8080
cd backend
mvn spring-boot:run

# Терминал 2 — фронтенд на :5173 (запросы /api проксируются на :8080)
cd frontend
npm install
npm run dev
```

Откройте http://localhost:5173.

## Тесты

```bash
cd backend && mvn test            # раннер, API и все уроки
cd frontend && npm run build      # проверка типов + сборка
```

`LessonsContentTest` проверяет каждый урок: эталонное решение из `backend/src/test/resources/solutions/` должно проходить все тесты, а стартовый код — компилироваться, но не проходить.

## Сборка и деплой

```bash
docker build -t byte .
docker run -p 8080:8080 byte
```

Образ собирает фронтенд, кладёт его в статику Spring Boot и запускает всё одним процессом от непривилегированного пользователя.

### Настройки

Параметры в `application.yml` (или переменные окружения, например `BYTE_RUNNER_TIMEOUT=10s`):

| Параметр | По умолчанию | |
|----------|--------------|--|
| `byte.runner.timeout` | `5s` | Лимит времени программы, включая старт JVM |
| `byte.runner.max-memory-mb` | `128` | Куча дочерней JVM |
| `byte.runner.max-output-bytes` | `65536` | Максимум вывода, после чего программа останавливается |
| `byte.runner.max-concurrent-runs` | `4` | Одновременных запусков; остальные ждут в очереди |
| `byte.runner.queue-timeout` | `10s` | Сколько запрос ждёт в очереди, прежде чем получить 503 |
| `byte.runner.max-source-length` | `50000` | Максимальная длина кода |

## Как добавить урок

1. Создайте каталог `backend/src/main/resources/lessons/NN-slug/` (номер задаёт порядок, `slug` — адрес урока).
2. Добавьте файлы:
   - `lesson.json` — модуль, название, краткое описание и тесты:
     ```json
     {
       "module": "Первые шаги",
       "title": "Название",
       "summary": "Одна строка для списка уроков.",
       "tests": [
         { "name": "Пример", "stdin": "2 3\n", "expectedOutput": "5\n", "hidden": false }
       ]
     }
     ```
   - `theory.md` — теория (Markdown, блоки ```` ```java ```` подсвечиваются);
   - `task.md` — условие задания;
   - `Main.java` — стартовый код.
3. Положите эталонное решение в `backend/src/test/resources/solutions/slug.java` и добавьте `slug` в `LessonsContentTest.slugs()`.

Вывод сравнивается без учёта `\r\n`, пробелов в конце строк и пустых строк в конце.

## Безопасность

Каждая программа выполняется в **отдельной JVM** с лимитами по времени, памяти и объёму вывода, с пустыми переменными окружения; сервер не выполняет пользовательский код в своём процессе (классы для поиска `main` загружаются без инициализации).

Этого достаточно для разработки и закрытого использования, но **не является полноценной песочницей**: дочерний процесс имеет те же права, что и сервер, — доступ к сети и файлам внутри контейнера. Перед публичным запуском нужно изолировать каждый запуск (см. дорожную карту) и включить ограничение частоты запросов.
